### Why A1 should not become a large prerequisite

Even if a quantizer's error had zero mean, the model's output probability is a nonlinear function of the perturbed K/V, so expected probability changes need not be zero. Greedy decisions add threshold effects. Actual quantization error is input- and model-dependent; it is not generally independent of the unlearning shift. Neither fact predicts preferential restoration of forgotten knowledge. A positive aggregate effect must be measured and compared with full/retain-only controls; a negative effect is scientifically allowed.

The review's weight-rounding explanation is also an intuition, not a universal identity: an update smaller than a quantization step can still cross a rounding boundary, and changes in scales/outliers matter. For a cache mechanism study, compare directions and attention/output effects as well as magnitudes. On a teacher-forced shared token path, measure F/U K/V differences using the same layer/head layout and RoPE convention. Free-running paths diverge, confounding activation comparisons. Large reconstruction error does not by itself mean information recovery.

For uncertainty, define whether the target is these fixed benchmark authors or a population of authors. Author resampling alone does not capture variability across independently trained/unlearned checkpoints. More prompts, more generation seeds and more training seeds answer different questions.
